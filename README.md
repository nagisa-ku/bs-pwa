# Book Search

CSVファイルから書籍データを読み込み、検索・表示するWebアプリケーションです。

## 概要
このツールは、以下の処理を行います。
- CSVファイルのアップロードと解析（ISBN、タイトル、サブタイトル、巻、著者）。
- ISBN、タイトル、または著者によるキーワード検索機能。
- 検索結果のテーブル表示（タイトルの省略表示、巻の右寄せなど）。
- Service Workerを使用したPWA対応。

## 準備
### システム要件
- モダンなブラウザ（Chrome, Edge, Firefox等）がインストールされていること。

### 必要ライブラリのインストール
このアプリケーションは純粋なHTML/JavaScriptで動作するため、追加のライブラリインストールは不要です。

## ファイル構成
- `index.html`: メインのUIおよび検索ロジックを含むファイル。
- `manifest.json`: PWA（Progressive Web App）のためのマニフェストファイル。
- `service-worker.js`: オフライン動作やPWA機能を実現するサービスワーカー。
- `BaseData.csv`: 初期状態で読み込まれるデフォルトの書籍データ。

## 使い方
1. ブラウザで `index.html` を開きます。
2. 「ファイルを選択」ボタンからCSVファイルをアップロードするか、初期データのまま使用します。
3. 検索窓にISBN、タイトル、または著者を入力して検索します。

## 出力仕様
- **表示形式**: テーブル形式で結果を表示。
  - タイトル: 最大8文字まで表示し、超える場合は「…」で省略。
  - 巻: 右寄せで表示。
  - サブタイトル: 全文表示（ツールチップに全文を表示）。

## 注意事項
- CSVファイルのフォーマットは `ISBN, Title, Subtitle, Vol, Author` の順序を想定しています。
- PWAとして動作させるには、適切なWebサーバー上で配信する必要があります。
